Claude Code plugin

Video Translator Setup

Turn one finished short-form video with a voiceover into versions in other languages, spoken in your own ElevenLabs voice. The clips are re-timed so every cut still lands on the right word.

What you need

  • A Mac with Claude Code and a Claude subscription.
  • An ElevenLabs account with a voice you want to use. You'll need its API key and the voice's ID. Each person uses their own account and credits.
  • Homebrew, to install the two tools below.

Install

Run these in the macOS Terminal app.

  1. Install the tools

    brew install ffmpeg uv

    ffmpeg edits the video and uv runs the scripts.

  2. Add the plugin source

    claude plugin marketplace add gparadelo/video-translator

  3. Install the plugin

    claude plugin install video-translator@video-translator

  4. Enter your settings

    Start Claude Code in the terminal:

    claude

    Type /plugin, go to Installed → video-translator → Configure, and fill in:

    • ElevenLabs API key: create one in your ElevenLabs account under API keys. It's stored in your Mac's Keychain, never in a file.
    • ElevenLabs voice ID: open your voice in ElevenLabs and copy its ID.
    • Jobs folder: where your videos go. The default, ~/Documents/Video Translations, is fine for most people; it's created the first time you use the plugin. To use another folder, type its full path, such as ~/Movies/Translations. Tip: drag the folder from Finder into the Terminal window to paste its path.

    Only type the API key into this form. Never paste it into a chat with Claude or into a terminal command.

  5. Check everything works

    Start a new Claude Code session (terminal or desktop app) and run:

    /video-translator:setup

    Every line should say ok or set. If something doesn't, Claude explains how to fix it.

Translate a video

For each video, make a folder inside your jobs folder and put the finished video in it:

Documents/Video Translations/
└── summer-ad/
    └── base.mp4      # the finished video (any single .mp4 or .mov)

Then, in Claude Code:

/video-translator:translate summer-ad

This translates into the default languages (English, Spanish, German, French and Italian, minus the original). To pick languages, add their 2-letter codes after the name, for example /video-translator:translate summer-ad nl pt for Dutch and Portuguese.

The voiceover is transcribed into script.txt and its language is detected, so you don't need to write anything. If you have a written script, you can put it in the folder as script_original.txt; it's only used to spell names correctly.

Results appear in summer-ad/out/: one video per language. Claude tells you if any cut didn't land quite on its word, and at what time, so you know where to look.

Good to know

A cut is detected in the wrong placeEdit cuts.txt in the video's folder (one time in seconds per line), then ask Claude to run the translation again. You can also add a time to sync something inside a clip, like the moment a light changes colour.
It costs ElevenLabs creditsEach beat is voiced once and cached, so re-running only pays for the sentences that changed.
Changing the default languagesCreate a file named config.toml in your jobs folder with one line, for example languages = ["en", "es", "de", "fr", "it", "nl"].
A different voice for one languageCreate a file named .env in your jobs folder containing a line like ELEVENLABS_VOICE_ID_DE=your-german-voice-id.
Getting updatesRun both commands, then start a new Claude Code session. 
claude plugin marketplace update video-translator
claude plugin update video-translator@video-translator
"The tools aren't available"Claude Code couldn't start the plugin, usually because uv isn't installed. Run step 1 again, then restart Claude Code.
"Repository not found" when adding the pluginCheck the name is typed exactly as gparadelo/video-translator.
